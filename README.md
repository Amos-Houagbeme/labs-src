# labs-src — Systèmes, Réseaux & Cloud

Dépôt de travaux pratiques réalisés dans le cadre de ma formation en licence SRC à ESGIS Cotonou
et de ma préparation aux certifications réseau et cloud.

---

## Structure

```
labs-src/
├── reseau/       # Packet Tracer, VLANs, routage, Wireshark
├── linux/        # CLI, permissions, LVM, Bandit challenges
├── winserver/    # AD DS, DNS, DHCP, GPO, IIS, WSUS
├── cloud/        # AWS — EC2, VPC, S3
├── docker/       # Dockerfiles, Compose, microservices
└── scripts/      # Bash — monitoring, backups, automatisation
```

## Stack & outils

KVM/QEMU · VirtualBox · Cisco IOS · Windows Server 2025 · Kali Linux · Docker
